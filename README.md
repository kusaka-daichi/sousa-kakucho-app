# 操作性改善アプリ

Windows のパソコン操作を少し楽にする、小さな常駐アプリです。使いたい機能だけをスイッチでオンにして使います。

**共有ページ（ダウンロード）：https://kusaka-daichi.github.io/sousa-kakucho-app/**

- **モニター入れ替え**：左Ctrl を素早く2回で、左右の画面のウィンドウを入れ替える
- **かんたんスクショ**：PrintScreen を押すだけで、直感的にスクショ（デスクトップの「スクショ」フォルダに保存）
- **後ろを触る（透かし）**：無変換を押している間、ウィンドウを透かして後ろやデスクトップを触れる
- **操作マニュアル自動作成**：右Ctrl（または右Alt）を2回で記録開始。もう一度2回で、写真入りの手順書ができる

## 仕組み
- Windows に最初から入っている PowerShell と .NET だけで動きます（ほかのソフトのインストールは不要。exe も作りません）
- 中身は `app/` のファイルがすべてです（`app.cs` が本体、`app.html` が設定画面）
- 新しい版が出ると、アプリが自分で取ってきて更新します。外に送る情報はありません（GitHub に最新版を見に行くだけです）
